# Windows 被控服务

## 安装与使用

运行 NSIS 安装包，以管理员权限安装，默认目录为 Program Files，也允许选择 D 盘等自定义位置。安装器同时注册 `VntRemoteService`（LocalSystem），全新安装默认手动启动，不打开远程监听。服务程序 `vnt-service.exe` 随安装包交付。选择系统 Program Files 以外的位置时，安装器显示安全风险提示，明确选择“是”后继续；选择“否”则中止安装。静默安装默认拒绝自定义位置，不自动接受风险。安装器不修改所选安装目录的访问权限；管理员应确保 SYSTEM 可访问程序，并保护目录及父目录，防止普通用户替换以 SYSTEM 身份运行的程序。被控配置通过认证 TCP 交给服务读写，config.json 仅 SYSTEM 和管理员可访问；安装目录及服务程序不开放普通用户写权限。

运行安装版桌面时，同一 Windows 会话已有安装版进程则恢复原窗口；没有桌面进程时请求一次管理员授权，先停止仍在运行的 Windows 服务，等待服务及其桌面、代理退出，再启动服务。启动入口随后退出，由服务启动发起操作的当前交互登录用户的桌面界面（支持 RDP）；取消授权或服务未安装时显示错误，不循环提权。服务启动不要求被控密码。首次安装默认关闭被控，可在“允许访问本机”选择共享目标并开启；空白密码允许免密访问。被控启停通过本地 TCP 通知服务，无需再次提权；停止被控保留 Windows 服务及桌面。被控开关由服务记住，下次服务启动时恢复。设置页的“Windows 服务开机启动”只改变 SCM 启动类型，不要求密码，也不改变当前被控开关；开启后未登录时运行服务，登录后启动桌面。关闭主窗口隐藏到托盘，托盘“退出”停止桌面、被控和 Windows 服务；退出不改变被控开关的持久化值。

Windows 免安装版也按当前会话限制为一个进程，重复打开恢复原窗口。安装版与免安装版使用独立的单实例标识，可同时运行；启动入口交接期间也持有对应标识，连续双击不会重复启动服务或桌面。进程退出或被终止后由 Windows 自动释放标识，下次启动不受残留锁文件影响。

被控设置操作完成后自动保存：密码与端口输入框编辑结束时保存，选择显示器、生成随机密码及切换开关后立即保存，不需要额外点击保存按钮。主界面按操作顺序通过本地服务 TCP 保存配置，服务串行校验并写文件，保存不阻塞后续编辑，也不覆盖尚未完成的新输入；开启被控前先完成配置保存；被控启停不提权，设置自启独立通过管理助手请求管理员授权，不保存或校验被控配置。取消授权或保存失败后结束本次操作，不继续提权；取消授权不改变服务运行或自启状态，已写入的配置保留。被控运行期间端口不可编辑，后端同样拒绝修改；停止被控后即可更改端口，Windows 服务可以继续运行。除端口外，密码、共享显示器、剪贴板同步、共享系统音频、允许控制和硬件编码均可在运行期间保存，对新会话生效，无需重启被控；已有会话及其恢复过程保持原设置。安装版按会话配置复用代理，免安装版按显示器共享采集并在会话注册时固定剪贴板权限。每个新会话在认证时读取配置快照，配置读取失败时拒绝连接，空白密码允许免密访问。

“显示被控边框”默认关闭，保存后实时更新当前所有采集会话，不新建采集源，也不要求重新连接。安装版通过现有代理控制通道通知所有活动代理，重建代理时读取最新的边框设置；免安装版直接更新当前进程。该开关控制 WGC 的系统提示边框；DXGI/GDI 和安全桌面采集没有此系统边框。Windows 拒绝无边框权限时，首次采集回退 DXGI/GDI；已有采集更新失败时记录错误并继续推流，保持系统允许的显示状态。

安装版未安装服务时，桌面启动入口显示“请先安装”并结束，不创建主界面。版本由构建特性决定；复制安装版程序不会变成免安装版。`npm run tauri dev` 默认运行免安装版，不构建、安装或调用 Windows 服务。安装版构建使用 `npm run build:installed`。

免安装版使用 `npm run build:portable` 构建，当前 GUI 进程直接提供普通桌面的被控能力，不使用服务或会话代理。锁屏、UAC 或桌面暂不可用时保留连接和心跳，暂停画面、音频、输入及被控剪贴板，结束文件传输；普通桌面恢复后重建必要的媒体资源，通过流重置和关键帧恢复。免安装版不提供 Ctrl+Alt+Del、未登录连接、自启或跨注销/用户切换恢复。关闭窗口后驻留托盘，退出程序时停止被控。

两版本共用当前用户应用数据与 WebView 存储，添加的设备、主题和主控偏好可相互看到。安装版仍使用安装目录的被控配置；免安装版单独使用应用数据目录的 `portable/config.json`，密码同样由 DPAPI 加密，读取配置失败时拒绝新连接。两个被控实例占用同一端口时明确报告冲突。免安装更新入口仅打开发布页，手动下载替换 portable EXE。

密码和其他被控设置由服务读取安装目录的 `config.json`，通过认证 TCP 返回桌面回显；初始化加载同样使用认证的服务 TCP。密码框默认遮挡，点击眼睛按钮可查看已保存密码。普通保存保留原密码；明确清空密码输入框并结束编辑会清除访问密码。

远程窗口普通标题栏和全屏浮条都提供 Ctrl+Alt+Del 按钮。它使用服务端 SendSAS，而不是将三个普通按键模拟成安全注意序列。观看模式不允许键鼠或 SAS。发送时由 SCM 注册的 LocalSystem 服务在独立线程中直接调用 `SendSAS(false)`，保持服务身份；不模拟登录用户，也不修改 SYSTEM 令牌会话号。调用前验证当前进程就是 SCM 服务进程，目标仍为物理控制台会话，Windows 负责把 SAS 交给物理控制台；当前采集目标为 RDP 时明确拒绝 SAS，不将其发送给其他会话。SendSAS 本身无返回结果，界面仅对较慢的切换或失败显示提示；服务随后观察会话代理的输入桌面，8 秒内未检测到 Winlogon 安全桌面时报告结果未确认，不把“指令已发送”当作成功。普通窗口和全屏模式都显示系统策略、会话变化及超时原因，全屏浮条隐藏时提示仍可见。操作系统自身的登录验证和 UAC 流程仍正常执行。

## 进程与权限边界

- Tauri 主界面通过本地 TCP 管理被控、查询状态并运行主控连接，不持有进程内被控实例。主控剪贴板按远程窗口的同步设置控制，独立于本机被控配置的剪贴板开关。
- Windows 服务独立监听 `127.0.0.1:0`，通过 `--local-service-port <port>` 告诉桌面实际端口；本地控制端口不开放防火墙，与被控端口独立。命名管道用于可信引导：桌面验证管道内核服务 PID 与 SCM 一致，服务验证已安装桌面路径、已连接的交互会话及登录代次，再交付随机 TCP 凭证；凭证不放入命令行和日志。TCP 使用版本号、请求 ID、长度前缀 JSON 及结果/错误，消息上限 64 KiB，握手和普通请求 5 秒、被控启停 20 秒。显示窗口和关闭通知使用 TCP 长连接，断开后重新校验服务并取得凭证。
- 服务管理一份桌面，使用用户令牌、用户环境和普通桌面启动界面。手动启动选择发起操作的已连接交互会话，支持 RDP；切换会话时关闭旧界面并撤销其管理凭证。在同一会话中重复启动显示现有窗口。无手动选择时优先已登录的物理控制台，否则选择已连接的交互会话；没有可用登录时等待。RDP 断开或用户注销后保留服务及被控，重新选择可用会话；登录代次变化后不沿用旧身份。崩溃后按 250、500、1000、2000 毫秒上限退避重拉。更新器启动安装器前通过 TCP 暂停重拉 120 秒，失败时解除暂停；桌面 Job 允许安装器子进程脱离，避免服务停止终止安装器。
- Windows 服务状态 `serviceState` 与被控状态 `state` / `running` 分开返回。被控使用独立取消令牌，停止后等待 TCP/UDP 释放并清理缓存的媒体/用户代理；服务本地控制通道继续运行，再次启动重新读取配置。
- 系统服务持有对外 TCP/UDP 连接和认证状态，在所选被控交互会话中启动无窗口代理。服务本身不在 Session 0 抓屏。
- 每个被控交互会话、登录身份及桌面代次复用一个 SYSTEM 媒体代理。代理共享采集源、键鼠归属记录，按远程连接独立编码。安全桌面使用 DXGI 并切到主显示器以展示登录或 UAC 界面；恢复普通桌面时重新使用配置的显示器及 WGC/DXGI/GDI。
- 音频和 OLE 文件剪贴板在登录用户权限的独立代理中共享。代理通过 SCM 的实际服务 PID、已安装映像路径及命名管道内核 PID 校验服务身份，不要求普通用户打开 SYSTEM 进程。初始化失败会返回原因，用户会话管道完成剪贴板注册握手后才开始转发；启动期间只保留最新文本或文件清单，桌面或用户变化时清空，不重放文件读取请求。锁屏、UAC、注销或用户切换时暂停这些能力并结束旧文件操作，恢复后重新绑定当前用户。
- 代理的根管道与会话管道均由服务创建，拒绝远程命名管道客户端，检查内核返回的进程 ID；代理也检查父进程映像和 SCM 服务进程身份。启动凭证只经管道传递。
- 管道、媒体队列和帧长度均有上限。代理放入关闭即终止的 Windows Job；退出留出有限时间释放键鼠，服务退出后不遗留代理。
- 桌面变化或代理故障后，服务保留远程连接并后台重建代理，继续回应心跳。代理每 50 毫秒检查输入桌面，服务每 100 毫秒检查会话；变化后立即重建，失败时按 250、500、1000、2000 毫秒上限退避。退出中的代理先关闭接入管道，不等待整个进程清理完毕再失效。主控立即清空旧画面并丢弃旧解码队列；短暂切换只显示中性底色，600 毫秒后显示轻量提示，3 秒后显示具体原因和操作入口。恢复时重置流并请求关键帧，新桌面的首帧实际绘出后遮罩淡出，不等待每秒统计刷新；按新桌面的时间戳下限拒绝迟到的旧 TCP/UDP 帧。

被控采集优先选择已连接的物理控制台；物理控制台未连接时，选择唯一已连接的 RDP 会话。没有已连接会话时回到物理控制台，以保留未登录和锁屏访问；多个 RDP 会话同时连接且无已连接控制台时明确报错并暂停采集，不猜测目标。元数据探测、媒体代理、音频/剪贴板代理和连接恢复使用同一选择规则；会话切换后退出旧代理，清空旧画面和文件状态。桌面管理界面也可以运行在 RDP 会话中。不提供虚拟显示器，无可用显示器时报告状态并重试。首次连接若尚无法完成采集代理握手，会返回明确的连接错误。直连 TCP/UDP 的控制与媒体内容不加密；QUIC 使用 TLS 1.3，VNT 使用核心加密能力。双方协议版本均须为 1；外部连接及服务到会话代理的认证均使用独立 nonce 的 HMAC-SHA256 挑战响应。

## 配置、日志与安装生命周期

- `<安装目录>\config.json`：唯一的被控配置文件，包含端口、显示器、控制能力等设置和 `passwordDpapi` 加密密码。桌面初始化、读取回显及保存均通过认证 TCP 的 `ReadConfig` / `SaveConfig` 请求交给 Windows 服务，不直接访问服务配置文件。服务与被控启停串行处理，校验配置及实际被控监听端口，密码留空保留原密码，重新计算密码配置标记后写盘，成功落盘才确认保存。新连接认证直接读取最新文件，已有连接保持不变。读写失败返回具体错误，桌面不回退到本地文件访问。文件仅 SYSTEM 和管理员可读写，服务启动及安装时校验并设置 ACL；安装目录、服务程序及私有状态保持原权限。写入仍独占现有文件、刷新后释放，读取等待写入完成。服务未运行时不能读写安装版配置；免安装版继续直接读写当前用户目录配置。SCM 状态查询仅提供服务元数据，不读取配置。
- `<安装目录>\private\host-enabled.json`：服务管理的被控开关，独立于普通配置；成功启停后原子保存，保存失败回滚运行状态。缺少文件时初始化为关闭，与是否配置密码无关。文件损坏时保留服务和桌面、拒绝自动开启被控并报告错误。
- `<安装目录>\service-state.json`：最近一次服务操作或启动失败的具体原因。服务退出后仍可查询，界面显示完整错误，不用依赖日志或只看 SCM 通用退出码；新操作开始时清除旧错误。
- `<安装目录>\logs\vnt-remote.log`：被控服务日志，按服务程序位置定位，不受当前工作目录影响。
- `<安装目录>\logs\vnt-installer.log`：安装、升级、卸载辅助程序日志，与服务日志分开轮转，避免并发占用。两类日志均为单文件 2 MiB，保留两份备份；普通用户可读，仅管理员及 SYSTEM 可写。
- 输入由代理中的独立、无窗口线程绑定输入桌面后执行，显式申请 `DESKTOP_JOURNALPLAYBACK` 输入注入权限；仅有抓屏所需的桌面权限会使键鼠注入遭到拒绝。服务日志记录会话是否仅观看、首次收到输入及代理首次执行成功；注入失败会返回具体 Windows 错误并显示在远程窗口，同一故障最多每 5 秒报告一次，不记录按键内容或账号密码。
- 主控及界面日志位于当前用户应用数据目录的 `logs/`。

升级前记录自启设置与 Windows 服务实际运行状态，停止服务、受管理桌面和代理；升级后分别恢复启动类型和运行状态，原先手动停止的自动服务仍保持停止。普通卸载停止并删除服务、删除本程序的防火墙规则、按记录恢复由本程序修改且仍保持原应用值的 SAS 策略；安装目录中的配置、日志与私有状态保留。防火墙只开放所选 TCP/UDP 端口的专用网络、本地子网访问。

## 自动验证与双机验收

自动验证包括：前端测试和构建、Rust 核心及主控测试、安装目录配置及密码往返、真实 TCP/UDP 端口占用及故障原因保留、真实命名管道进程身份与大小边界、DPAPI 往返和篡改拒绝、自启失败回滚、共享会话的独立退出、TCP/UDP 三种编码、音频故障隔离及剪贴板端到端回归。运行：

```powershell
npm test
npm run lint
npm run build
cargo test --workspace
npm run build:installed
npm run build:portable
```

默认 Cargo 应用检查使用免安装模式，不需要服务 sidecar。安装版构建入口会自动生成 sidecar。发布安装包位于 `target/release/bundle/nsis/`，免安装产物为 `target/release/bundle/portable/*-portable.exe`，直接运行，无需解压。

以下项目必须使用两台 Windows 机器和实际安装包人工验收，自动测试不能视为已通过这些场景：

- [ ] 全新安装：服务已注册但未启动；首次打开桌面 UAC 启动服务后由服务拉起界面。无密码可运行服务、设置自启并开启免密被控；配置密码后需认证。取消授权显示错误且不重复请求。
- [ ] 安装版关闭主窗口隐藏到托盘且仍能连接；托盘退出后桌面、被控及服务均退出，重新打开按上次开关恢复。停止被控保留服务和桌面，可更改端口后重新开启。复制安装版仍要求服务。免安装版在没有服务或已有服务的机器上均由本进程被控，退出后不能连接。
- [ ] 两版本先后运行时互见已添加设备、主题和主控偏好，被控配置保持独立；同时运行时设备增删改能够同步。
- [ ] 免安装版在锁屏/UAC 时清空旧画面并暂停，心跳保留；返回普通桌面自动恢复，暂停期间不能输入或传文件。Ctrl+Alt+Del 提示不支持。
- [ ] 开启自启并重启，未登录时从另一台机器连接，输入 Windows 凭据完成登录。
- [ ] 连续锁屏/解锁、注销/重新登录和快速切换用户，连接保留，旧画面被遮住并自动恢复。
- [ ] 操作管理员窗口；在 UAC 安全桌面确认和取消；发送 Ctrl+Alt+Del。
- [ ] 两个主控同时连接；一端断开或按住修饰键时切换桌面，不留下卡键。
- [ ] 普通桌面双向文字和文件复制粘贴，包括刚连接时复制、子目录、多文件、连续粘贴；主界面退出后仍可同步。
- [ ] 安全桌面不传剪贴板；文件传输被结束；恢复后没有跨用户文件句柄或清单。
- [ ] 杀死媒体/用户代理，画面或对应能力恢复，心跳不被代理重建阻塞。
- [ ] 启动/配置 UAC 取消、端口占用、显示器变化、系统声音设备不可用均有明确状态。
- [ ] 开关自启不改变被控状态；服务开机启动后按上次被控开关恢复，未登录时等待拉起桌面。关闭自启不停止当前服务。
- [ ] 重复打开显示原桌面；杀死桌面后重拉，注销后等待下次登录，快速切换用户清退旧桌面且旧桌面不停止服务。

## 排查连接与低帧率

连接详情显示目标、已应用帧率、抓屏耗时和编码耗时。目标与已应用值是限额，实际吞吐还受采集、编码、媒体代理、网络和绘制影响；不能仅凭已应用 60 FPS 推断应显示 60 FPS。抓屏与编码可并行，两个平均耗时不应直接相加推算端到端帧率。

主控日志每 5 秒记录远端视频管线统计，服务记录编码器及可靠通道发送错误的消息类型、通道与期限。TCP 帧边界 EOF、心跳超时和本地视频桥发送超时分别代表不同故障，应对照两端同一时间段日志。

UDP 整帧发送预算为 100 ms，到期或暂不可写时丢弃该帧并保留控制连接，暂停依赖受损参考链的 P 帧，按最多每 500 ms 一次请求关键帧；成功发送关键帧后恢复。永久 socket 错误会报告故障；可靠 TCP/命名管道写入超时结束对应通道，避免继续使用写入了部分帧的字节流。

自动测试与回环模拟不能替代上述真实安装、重启、锁屏/UAC、用户切换和双机验收。
